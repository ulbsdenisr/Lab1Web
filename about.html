About

Simple VIN lookup app

This project is a minimal vehicle lookup tool built to decode a VIN and display a few useful details such as year, make, model, trim, engine, and drivetrain.

It uses the CarsXE API and keeps the interface intentionally simple so it is easy to understand and expand later.

  • Input a 17-character VIN
  • Send the request to the CarsXE specs endpoint
  • Display the returned vehicle attributes
  • Keep the design compact and easy to customize
